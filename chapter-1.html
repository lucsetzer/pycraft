Exercise 2: Variables

Create a variable called city and store the name of your city as a string.
Create a variable called year and store the current year as a number.
Use print() to display both variables.

# Nothing needed here # Create a variable called 'city' and store your city name # Create a variable called 'year' and store the current year # Print both variables # Create a variable called 'city' and store your city name city = "New York" # Create a variable called 'year' and store the current year year = 2025 # Print both variables print(city, year) # Check if 'city' exists test_object("city", incorrect_msg="You need to create a variable called 'city'.") # Check if 'city' is a string (not required but helpful) # test_data_type("city", "str", incorrect_msg="city should be a string, like 'London'.") # Check if 'year' exists test_object("year", incorrect_msg="You need to create a variable called 'year'.") # Check if 'year' is a number # test_data_type("year", "int", incorrect_msg="year should be a number, like 2025.") # Check if print() was used test_function("print", incorrect_msg="You need to use print() to display your variables.") # Check if both variables were printed # This checks the output contains text (city name will be printed) # Note: We can't check exact values since students use different cities test_output_contains("city", incorrect_msg="Make sure you're printing the 'city' variable. Stuck? Try this:

Exercise 3: Basic Math Operations

Create two variables called num1 and num2 and assign any two numbers.
Perform these operations and print the results:

  • Add num1 and num2
  • Subtract num2 from num1
  • Multiply num1 and num2
  • Divide num1 by num2
# Nothing needed here # Create two variables and assign any numbers # Addition # Subtraction # Multiplication # Division # Create two variables and assign any numbers num1 = 10 num2 = 3 # Addition print(num1 + num2) # Subtraction print(num1 - num2) # Multiplication print(num1 * num2) # Division print(num1 / num2) # Check if 'num1' exists test_object("num1", incorrect_msg="You need to create a variable called 'num1'.") # Check if 'num2' exists test_object("num2", incorrect_msg="You need to create a variable called 'num2'.") # Check if both are numbers (optional) # If students use strings, this will give a helpful error # Check if print() was used at least once test_function("print", incorrect_msg="You need to use print() to show your results.") # Check if addition was printed (by checking output) # This is tricky because we don't know what numbers students used # We'll check that the output contains numbers (simplified) test_output_contains("num1", incorrect_msg="Make sure you're printing the results of each operation.") # Success message success_msg("🎉 Excellent work! You performed all four operations!")
Stuck? Try this:
1. num1 = 10 and num2 = 3
2. Addition: print(num1 + num2)
