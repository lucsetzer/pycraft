Exercise 2: Accessing List Elements

Create a list called colors with four colors of your choice.
Print the first color and the last color using their index positions.

# Nothing needed here # Create a list called 'colors' with four colors # Print the first color using index # Print the last color using index # Create a list called 'colors' with four colors colors = ["red", "blue", "green", "yellow"] # Print the first color using index print(colors[0]) # Print the last color using index print(colors[3]) # Check if 'colors' exists test_object("colors", incorrect_msg="You need to create a variable called 'colors'.") # Check if 'colors' is a list with at least 4 items test_object("colors", incorrect_msg="Make sure 'colors' is a list with at least 4 colors.") # Check if print() was used at least once test_function("print", incorrect_msg="You need to use print() to display the colors.") # Check if the first color was printed # Since we don't know what colors students used, we check the output test_output_contains("colors", incorrect_msg="Make sure you're printing the first color using index 0.") # Check if the last color was printed # This is trickier - we can check if the output contains at least 2 lines # (simplified check) test_output_contains("colors", incorrect_msg="Make sure you're printing the last color using index -1 or the last index.") # Success message success_msg("🎉 Excellent! You accessed list elements using indices!")
Stuck? Try this:

You added a city to your list using .append()!")
Stuck? Try this:
