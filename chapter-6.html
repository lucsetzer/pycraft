Exercise 3: Removing Dictionary Items

Starting with the car dictionary from Exercise 2 (with keys: brand, model, year, color):

  • Remove the "color" key using del
  • Use pop() to remove the "model" key
  • Print the resulting dictionary
# This code runs before the student's code to set up the dictionary car = { "brand": "Toyota", "model": "Camry", "year": 2022, "color": "blue" } # Remove the "color" key using del # Remove the "model" key using pop() # Print the resulting dictionary # Remove the "color" key using del del car["color"] # Remove the "model" key using pop() car.pop("model") # Print the resulting dictionary print(car) # Check if 'car' exists test_object("car", incorrect_msg="The 'car' dictionary should exist.") # Check if "color" was removed using del test_object("car", incorrect_msg="Remove the 'color' key using del.") # Check if "model" was removed using pop() test_object("car", incorrect_msg="Remove the 'model' key using pop().") # Check if the dictionary was printed test_function("print", incorrect_msg="Print the resulting dictionary using print().") # Check if "color" is gone from output # We'll check for the remaining keys test_output_contains("'brand'", incorrect_msg="Your dictionary should still have the 'brand' key.") test_output_contains("2022", incorrect_msg="Your dictionary should still have 'year' with value 2022.") # Success message success_msg("🎉 Perfect! You successfully removed keys using del and pop()!")
Stuck? Try this:
1. Remove with del: del car["color"]
2. Remove with pop(): car.pop("model")
3. Print: print(car)

Remember: del removes a key-value pair permanently,
while pop() removes it but also returns the removed value (if you need it).

Exercise 4: Looping Through a Dictionary

Starting with the car dictionary (with keys: brand, model, year):

  • Write a loop to print all keys and values in the car dictionary
  • Modify the loop to print a sentence like "The brand of the car is Toyota" for each key-value pair
# This code runs before the student's code to set up the dictionary car = { "brand": "Toyota", "model": "Camry", "year": 2022 } # Loop through the dictionary and print all keys and values # Modify the loop to print a sentence for each key-value pair # Loop through the dictionary and print all keys and values for key, value in car.items(): print(key, value) # Modify the loop to print a sentence for each key-value pair for key, value in car.items(): print(f"The {key} of the car is {value}") # Check if 'car' exists test_object("car", incorrect_msg="The 'car' dictionary should exist.") # Check if .items() was used to loop test_object("car", incorrect_msg="Use .items() to loop through key-value pairs.") # Check if print was used with both key and value test_function("print", incorrect_msg="Use print() to display the keys and values.") # Check if the output contains the sentence format test_output_contains("The", incorrect_msg="Print a sentence like 'The brand of the car is Toyota'.") test_output_contains("of the car is", incorrect_msg="Use the format: 'The [key] of the car is [value]'.") # Success message success_msg("🎉 Excellent! You mastered looping through dictionaries!")
Stuck? Try this:
1. Loop through key-value pairs:
for key, value in car.items():
    print(key, value)
2. Print a sentence:
for key, value in car.items():
    print(f"The {key} of the car is {value}")
