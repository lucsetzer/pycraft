Exercise 1: Introduction to Matplotlib

Exercise 5: Creating Histograms

Create a histogram with the data [2, 3, 3, 4, 4, 4, 5, 6, 6, 7, 8, 8].
Use 6 bins and a red color for the bars.
Add a title and labels for the axes.
